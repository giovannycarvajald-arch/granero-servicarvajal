# Granero Servicarvajal

Primera versión de la tienda virtual.

## Incluye
- Catálogo de demostración con categorías y búsqueda.
- Carrito de compras.
- Formulario de pedidos para domicilio o recogida.
- Panel administrativo de demostración para agregar, editar y eliminar productos.
- Vista de pedidos y cambio de estado.

## Importante
Esta versión es un prototipo local: usa `localStorage`, por lo que los pedidos y productos no se sincronizan entre dispositivos. La contraseña de demostración es `1234` y no es segura para producción. Antes de recibir pedidos reales se debe conectar una base de datos compartida, autenticación segura y WhatsApp.

## Publicación
El sitio se puede publicar con GitHub Pages desde Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
